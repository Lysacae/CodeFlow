# CodeFlow

Application Windows pour apprendre à programmer en **Python**, **C#**, **C++** et **Java**.

## Installation

Téléchargez la dernière version : [github.com/Lysacae/CodeFlow/releases](https://github.com/Lysacae/CodeFlow/releases)

- **Installateur** : `CodeFlow_*_x64-setup.exe`
- **Portable** : dossier `portable` / `Lancer-CodeFlow.bat`

Si Windows bloque l’éditeur non vérifié : utilisez le portable, ou autorisez l’app.

## Premiers pas

1. Créez un compte (pseudo, mot de passe, photo facultative) ou connectez-vous  
2. Choisissez un langage et suivez les leçons  

Compte et progression sont synchronisés (Supabase).  
Au lancement, une popup propose d’installer une version plus récente si une release GitHub est disponible.

## Prérequis

Windows 10 ou 11. Au besoin, CodeFlow propose d’installer les outils manquants.
