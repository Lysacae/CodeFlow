# CodeFlow Desktop

Application Tauri 2 + React.

```bash
npm install
npm run tauri:dev
npm run tauri:build
```

Voir [docs/INSTALL.md](../../docs/INSTALL.md) pour les runtimes et l'installateur.

## Versions de test

Ne pas publier les versions de test sur GitHub (`gh release create`, tags, ou envoi des installeurs) tant que ce n'est pas demandé explicitement. Recompiler uniquement en local : installateur NSIS et exécutable portable.
